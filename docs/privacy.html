Privacy policy

Aman Channel Studio is a personal, owner-operated publishing tool for Vice City - Unlocked and Kidzz Rhythm. Effective 22 November 2026.

Information accessed and its purpose

  • Google OAuth client credentials, refresh tokens, access tokens, and granted permissions authorize operations requested by the channel owner.
  • Channel identifiers and names are read to confirm that the correct channel is connected.
  • Video and playlist identifiers, titles, descriptions, public statistics, durations, and publishing times support topic research, duplicate-upload prevention, and publication checks.
  • Original scripts, narration, video files, upload receipts, and first-comment text are processed to produce and publish the owner's videos.

The app does not request passwords, payment information, Gmail access, or viewer contact lists. Viewers do not authorize accounts through this website. It does not intentionally collect information from children; a made-for-kids channel designation describes the published content, not an account-collection service for children.

Storage and third-party processing

The owner stores OAuth credentials and API keys as GitHub Actions repository secrets. Authorized workflow jobs access them at runtime to contact the relevant service. These credentials are not intentionally written into public source files, model prompts, or workflow logs.

Public research metadata and generated script text are processed by Google's Gemini API. Narration text is sent to the Edge TTS speech service. If configured, Pexels receives stock-footage search terms. Generated videos and publication metadata are sent to YouTube. GitHub hosts the source, workflow execution, logs, and artifacts. These services process information under their own applicable terms and privacy policies. The app does not sell Google account data or use it for advertising.

Small upload receipts, including video IDs, generated titles, timestamps, and intended first comments, are stored in the public repository's history directory. This can reveal metadata or a link for a private test upload, although YouTube controls access to the video itself. Do not include confidential information in generated publication text. OAuth credentials are excluded from this public history.

Retention and deletion

Production metadata artifacts are configured to expire after seven days. Workflow logs follow the repository's configured GitHub retention. Temporary rendered media are removed after upload or when the hosted job ends. Upload receipts and source files remain until the owner removes them. Removing current files does not automatically erase prior Git history, forks, or caches.

The owner can delete repository secrets, workflow artifacts, and history records through GitHub, and can delete uploaded videos and comments through YouTube Studio or the relevant YouTube interface. To request help with deletion or data handling, contact the operator below.

Control and revocation

You may revoke the app's access through Google Account permissions. Revocation stops future authorized operations but does not itself delete videos, comments, or stored repository records. To stop scheduled work, disable the workflow or its automation-enabled repository variable.

Website hosting

This documentation site has no application sign-in, advertising, or custom analytics. GitHub Pages may collect standard hosting request information under the GitHub Privacy Statement.

Google and YouTube policies

Use of Google API data is subject to the Google API Services User Data Policy and applicable YouTube API policies. Google's handling of data is described in the Google Privacy Policy.
